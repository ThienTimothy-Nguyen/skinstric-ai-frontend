## Skinstric AI

Skinstric AI is a demographic-analysis web application built during a virtual internship. The project focuses on frontend workflow, image submission, API integration, routing, and responsive UI development.

## Features

- Webcam image capture
- Image upload functionality
- User data submission
- API integration for demographic analysis
- Age, gender, and race prediction results
- Loading, validation, error, and navigation states
- Responsive multi-page interface
- Reusable component structure

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- Zustand
- GSAP
- API Integration

## Installation Instructions

```bash
git clone https://github.com/thientimothy-nguyen/skinstric-ai-frontend.git
cd skinstric-ai-frontend
npm install
npm run dev
```
